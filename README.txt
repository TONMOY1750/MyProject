========================================================
SPL1 E2EE Terminal Chat (Fixed Version)
BSSE1750 Midterm Defense Deliverable
========================================================

Supported Commands:
1. Set Name:
   /name <your_name>       e.g., /name tonmoy

2. Direct Message (Private E2EE DM):
   /msg <username> <msg>   e.g., /msg abid hello how are you

3. Send Encrypted File:
   /file <filepath>        e.g., /file README.txt

4. Help Menu:
   /help

Compilation Instructions:
- Double-click `build.bat` or execute `build.bat` from CMD.
- Run `server.exe` first, then launch multiple `client.exe` instances.
